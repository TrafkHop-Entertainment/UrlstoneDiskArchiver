# UrlstoneDiskArchiver
Urlstone Disk Archiver combines preexisting linux tools with a hand made GUI to make backing up and restoring media very easy!

### We have 3 main features:

1. DiskLink:
   With this, you can use drives from another pc over the internet! Very useful if you have a desktop pc with drives and want to work on a laptop that has no drive.
2. Archive
   Here you can backup your own media for private use! It automaticly detects what disk it is and uses the apropriate tool!
   We use a mixture of
   - dvdbackup
   - bluraybackup
   - ddrescue
   - cdcargo
3. Restore:
    With Restore, you can upscale and enhance singular video files OR whole disks inclusive disk menus! This whole dvd restore is a fully custom feature that has not been done anywhere else.

While the code was generated with the help of LLMs, the feel, user experience and GUI was hand crafted by us without the use of AI.
